# SSS DeFi Brand Assets

Public brand assets for SSS DeFi.

## Logo files

- `logos/sss-logo-square-black-1024.png` — recommended high-resolution square logo for listings such as DefiLlama.
- `logos/sss-logo-square-transparent-1024.png` — transparent-background version for integrations and media use.
- `logos/sss-logo-square-black-512.png` — smaller square logo for general display.
- `logos/sss-logo-icon-96.png` — original icon.
- `logos/sss-logo-icon-64.png` — small icon.

## Usage

For DefiLlama and other third-party listings, use the direct raw GitHub URL of:

```text
https://raw.githubusercontent.com/SSS-DeFi/sss-brand-assets/main/logos/sss-logo-square-black-1024.png
```

## Notes

These assets are public brand materials only. They do not include SSS core, asset hub, trading engine, deployment scripts, private keys, or internal operational code.
